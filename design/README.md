# Diseño

Material de **referencia**. No se compila ni se importa desde el frontend.

- `design-system/`: sistema de diseño original (tokens, 25 componentes en JavaScript, fuentes, guías). Se porta a TypeScript en `frontend/src/ds/` durante el Sprint 0.
- `pantallas/`: prototipos de las 38 interfaces (UI-01 a UI-38), una por historia del backlog. Cada archivo muestra estructura, textos y componentes esperados.

Los estados **Contratado, En curso, Cerrado y Liberada**, que faltaban acá, se definieron en el port: ver `frontend/src/ds/README.md`.
