Etiqueta corta con fondo suave para un dato (borrador, sin planner, 3 cambios).

**Vos pasás:** `tone` (`neutral`, `brand`, `accent`, `success`, `warning`, `danger`, `info`), `icon` opcional y `children`.

- El color acompaña, no dice: agregá ícono o palabra que carguen el significado.
- Para el estado de un evento o de stock usá `StatusChip`; para el salón, `SalonTag`.
