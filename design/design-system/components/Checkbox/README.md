Casilla con etiqueta y ayuda opcional, con una fila táctil de al menos 44 px.

**Vos pasás:** `label`, `hint`, `checked` / `defaultChecked` y `onChange`, `disabled`.

- Usala cuando la persona puede marcar varias opciones o una opción que se guarda con el formulario. Para algo que se aplica al instante, usá `Switch`.
- La etiqueta describe lo que pasa al marcar ("Evento de egresados"), no la acción ("Marcar").
