Resumen de un evento para listas, búsquedas y la programación del planner.

**Vos pasás:** `salon`, `status`, `tipo` (tipo de evento), `title`, `fecha`, `turno`, `invitados`, `vendedora`, `planner` (si falta se muestra "Sin planner") y `onOpen`.

- Arriba salón y estado; el título es lo más importante; abajo quién vendió y quién organiza.
- Todo el bloque abre el detalle con Enter o clic.
- Un evento sin planner es una advertencia visible, no un vacío: la administración la asigna.
