Etiqueta con el nombre y el color de identidad de un salón: Avril (rojo), Club de Campo (marrón) y Santa Bárbara (celeste), los mismos que ya usa la organización en su calendario compartido.

**Vos pasás:** `salon` (`avril`, `club`, `santa-barbara`) y `variant` (`tint` con fondo o `dot` solo punto y texto).

- El nombre siempre está: el color nunca alcanza solo.
- El color de salón es identidad, no estado: no lo uses para marcar éxito, error ni advertencia.
- En listas usá `tint`; en encabezados densos o tablas, `dot`.
