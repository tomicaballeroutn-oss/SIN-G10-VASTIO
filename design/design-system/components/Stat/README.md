Indicador con etiqueta, valor grande en numerales tabulares, unidad, variación y ayuda.

**Vos pasás:** `label`, `value` (texto ya formateado), `unit`, `delta` + `deltaTone` + `deltaIcon` (la variación como `Badge`) y `hint`.

- Un `Stat` responde una pregunta ("¿cuántos eventos confirmados?"). Mostrá tres como máximo por fila.
- La variación siempre lleva ícono y texto; el color no es el mensaje.
- No los uses de relleno: si el dato no cambia una decisión, no va.
