Interruptor de encendido y apagado que aplica el cambio al instante.

**Vos pasás:** `label`, `hint`, `checked` / `defaultChecked` y `onChange`, `disabled`.

- Usalo para preferencias y estados inmediatos (mostrar cancelados, usuario activo). Si hace falta un botón "Guardar", usá `Checkbox`.
- Lleva `role="switch"`; la etiqueta debe decir qué se activa, en positivo.
