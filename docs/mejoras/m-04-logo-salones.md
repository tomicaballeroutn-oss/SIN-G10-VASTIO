# M-04 · Logo por salón

## Alcance inicial

El primer uso es el comprobante interno de seña en PDF. Al emitirlo, el backend busca el logo por el código estable del salón (`avril`, `club` o `santa-barbara`), no por el nombre editable ni por el ID de base de datos. Cada marca se mantiene en una caja transparente de 172 × 76 puntos y conserva su proporción. Santa Bárbara tiene una variante positiva en azul oscuro, sin fondo, para que su marca blanca original se lea sobre papel claro; el archivo blanco original se conserva.

El PDF emitido conserva el logo junto con el resto del documento original. Las descargas posteriores devuelven esos mismos bytes y los comprobantes históricos no se regeneran.

La aplicación todavía no produce una orden de preparación descargable o imprimible. Cuando se incorpore ese documento, debe resolver el logo a partir del salón del evento y usar la misma caja visual.

## Otros lugares posibles

- **Ficha del evento:** el encabezado tiene espacio para una marca pequeña junto al nombre del salón. Es una buena segunda opción para dar contexto sin repetir el logo en toda la pantalla.
- **Tarjetas de cocina:** podría ayudar a identificar rápidamente el salón, pero conviene probar primero una marca pequeña junto a los datos de salón y turno.
- **Tarjetas de la lista y agenda mensual:** no se recomienda por ahora. Ya identifican el salón con nombre y color; repetir el logo en muchas tarjetas o en cada unidad recargaría la vista.
- **Reportes que abarcan varios salones:** conservar la marca de VASTIO. No corresponde destacar un logo de salón cuando el reporte representa a más de uno.
- **Contrato firmado que carga el usuario:** conservar el archivo original. No insertar ni modificar logos dentro de documentos subidos por el cliente.
